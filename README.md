# 🖌️ artlet

A **fun and interactive web-based paint application** built with **HTML, CSS, and JavaScript**. Draw, erase, change brush color, and even save your artwork—all in your browser! Perfect for beginners learning web development while building a creative project.

---

## Features

- ✏️ **Draw freely** on the canvas with adjustable brush size.  
- 🩹 **Eraser tool** to remove mistakes like MS Paint.  
- 🎨 **Brush color changer** to pick your favorite color.  
- 🖼️ **Canvas color changer** without losing existing drawings.  
- 🧹 **Clear canvas** button to reset the board.  
- 💾 **Save artwork** as PNG screenshot.
